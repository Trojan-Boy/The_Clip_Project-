# Task: Market Research and Local Model Coding

## Objective
- Find a real, unsolved problem in the market.
- Propose a software solution.
- Build the solution using only local AI models (no cloud APIs).

## Steps
1. Research market gaps and select a high-impact opportunity.
2. Pitch the project to the CTO for technical planning.
3. CTO requests CEO approval.
4. Upon approval, CTO hires and orchestrates local-model-based agents to code the solution.
5. Deliver the codebase and a summary of the approach.

## Constraints
- All AI/ML inference and code generation must use local models.
- No external API calls for core logic.
