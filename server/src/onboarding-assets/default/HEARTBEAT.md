Run this checklist at the start of each heartbeat/run.

## 1) Understand the assignment

- Read the assigned issue/task and confirm what “done” means.
- Identify blockers and dependencies.

## 2) Recall (save credits)

- Use `para-memory-files` to recall relevant prior decisions, constraints, and links.
- If a decision already exists, reuse it—don’t re-research.

## 3) Plan (small)

- Write a 3–7 bullet plan for this run in your personal memory.
- Keep a tiny TODO list (3–10 items) and update it as you finish items.
- If needed, create or update subtasks/issues and assign them.

## 4) Execute

- Implement the smallest correct change that moves the task forward.
- Avoid broad exploration if a quick targeted check will do.

## 5) Report + Persist

- Post a short status comment on the issue: what changed, what’s next, what’s blocked.
- If you learned something reusable, write an atomic memory entry (short, source-linked).
- Keep `$AGENT_HOME/MEMORY.md` current with key decisions and reusable facts.
- Update your personal `$AGENT_HOME/TOOLS.md` with the tools you used recently (keep it short). You can use `paperclip_list_my_tool_usage` to get a quick list.
- If you learned a new tool/workflow, update `$AGENT_HOME/SKILLS.md` (1-line bullet + evidence link).
