# Early Adopter Program Customer Tracking

This document outlines the key information to track for each early adopter customer to monitor progress towards the goal of 100 customers.

## Data Points to Track:
*   **Customer ID:** Unique identifier for each customer.
*   **Company/Individual Name:** Name of the early adopter.
*   **Contact Person:** Primary contact for communication.
*   **Contact Email:** Email address of the primary contact.
*   **Onboarding Status:** (e.g., Invited, Application Received, Approved, Onboarded, Active, Inactive, churned).
*   **Onboarding Date:** Date the customer was successfully onboarded.
*   **Feedback Channel:** How they provide feedback (e.g., dedicated Slack channel, regular calls).
*   **Key Feedback/Issues:** Summary of critical feedback or issues raised.
*   **Status of Feedback:** (e.g., Reviewed, In Progress, Resolved).
*   **Notes:** Any additional relevant information.

## Proposed Tracking Method:
Initially, a simple CSV file or a markdown table can be used to track this information. As the program scales, a dedicated CRM or customer success tool may be considered.
